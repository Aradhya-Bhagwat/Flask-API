A full-stack web application designed for practicing RESTful API CRUD (Create, Read, Update, Delete) operations using **FastAPI** as the backend framework, **PostgreSQL** as the relational database, and a **React** frontend.

---

## 📌 Features

- **Full-Stack Integration:** Connects FastAPI REST APIs with a dynamic React frontend.
- **Complete CRUD Operations:** Practice creating, reading, updating, and deleting records.
- **PostgreSQL Database Support:** Relational data persistence using PostgreSQL & SQLAlchemy / asyncpg.
- **Interactive API Docs:** Automatic, interactive API documentation generated by FastAPI (Swagger UI & ReDoc).
- **Asynchronous Execution:** High-performance asynchronous request handling powered by Uvicorn.

## ⚙️ Getting Started

### **Prerequisites**

Ensure you have the following installed on your local machine:
- [Python 3.8+](https://www.python.org/downloads/)
- [Node.js](https://nodejs.org/) & `npm`
- [PostgreSQL](https://www.postgresql.org/download/)

---

### **1. Backend Setup (FastAPI)**

1. **Activate Virtual Environment:**
   ```bash
   source myenv/bin/activate  # On macOS/Linux
   # myenv\Scripts\activate   # On Windows
   ```

2. **Install Required Packages:**
   ```bash
   pip install fastapi uvicorn psycopg2-binary sqlalchemy
   ```

3. **Database Configuration:**
   Ensure PostgreSQL server is running and configure connection settings within your FastAPI database setup.

4. **Run the FastAPI Server:**
   ```bash
   uvicorn main:app --reload
   ```
   - API will run locally at: `http://127.0.0.1:8000`
   - Interactive Swagger API docs: `http://127.0.0.1:8000/docs`
   - ReDoc alternative docs: `http://127.0.0.1:8000/redoc`

---

### **2. Frontend Setup (React)**

1. **Navigate to Frontend Directory:**
   ```bash
   cd frontend
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start Development Server:**
   ```bash
   npm start
   ```
   - React app will open locally at: `http://localhost:3000`

## 📡 API Endpoints Overview

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | Health check / Welcome greeting |
| `GET` | `/items` | Retrieve all items (Read) |
| `POST` | `/items` | Create a new item (Create) |
| `PUT` | `/items/{id}` | Update an existing item (Update) |
| `DELETE` | `/items/{id}` | Delete an item (Delete) |
